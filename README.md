# asmit/advanced-kanban

A production-ready Kanban board for Filament panels. Turn any status field into columns with drag-and-drop, workflow transitions, search, filters, pagination, and Filament actions on every card.

## Features

- **Drag and drop**: move cards between columns and reorder within a column
- **Workflow transitions**: restrict which columns a card can move to
- **Search and filters**: debounced search across fields and relations, plus Filament filter forms and tab filters
- **Pagination**: load more records per column on scroll
- **Actions**: header, column header, and record actions with full Filament support
- **Transition modals**: collect data before a card enters a column
- **Custom cards and columns**: generate and edit Blade components for your layout
- **Record locking**: prevent specific cards from being moved
- **Embeddable boards**: drop a board into any Filament page or resource view
- **Record infolists**: render card content from Filament infolist entries
